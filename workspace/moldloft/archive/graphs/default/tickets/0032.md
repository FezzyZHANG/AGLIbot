Simplified Super-agent Thread subscription. Task gains `origin` (platform, chat, message ref) and `threads[]`. The owner's private-chat L2 lists open task cards (id, title, status, last log line, about 160 chars each); L2 changes only when a task status changes. The chat model attaches a follow-up with `<补充 任务="<task-id>">...</补充>` (final syntax, matching the existing XML-like markers), appended to work/tasks/<id>/followups.md and to log.md.

Done when: "change that research to approach B" in chat lands in the right task's followups.md, and the reply names the task.

Implemented in fc54307 (Astra, reviewed by Opus). Task cards carry the log line frozen at the last status change, so ordinary log appends do not rebuild L2.
