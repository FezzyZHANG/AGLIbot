Today nothing in the runtime writes these paths, but there is no OS-level protection. Run the bot as a user without write access to them.

Prototype evidence: both of its session roles run with `danger-full-access` and command blocking is a PATH wrapper (src/app/sessions.ts:152, src/infra/environment.ts:98); a same-user process can bypass both. Role separation by prompt is not a security boundary, so keep OS-level write protection.
