DSH runs are recorded as model calls with model_id dsh:profile:<profile>. The --json events of the verified agli run carry the session and usage; take the provider/model from the events (or the profile default model when events do not name it) and record it as the model_id (e.g. dsh:bailian/deepseek-v4.1-flash), so spend can be attributed per model in daily reports and later in model scoring (#23).
