https://github.com/Ephemeral-AI-Lab/layerfs (paired with dsh-layerfs). Codex (gpt-6-astra, xhigh) evaluated it 2026-11-01 from source/docs/issues only; nothing installed or tested.

Verdict: adopt later behind a narrow TaskWorkspace trait (prepare/checkpoint/diff/discard/export), with git worktree + scratch as the default implementation. Do not make DSH installation depend on it.

Why not now: Windows means WSL2 + its own Docker + /dev/fuse + Node>=22; only the Disposable Store profile exists (SQLite synchronous=OFF, no crash durability); open reports of silent merge loss (#517) and inconsistent unmount state (#462); daemon container gets CAP_SYS_ADMIN with AppArmor off, so it is not a confinement boundary — L4 protection and an isolated DSH runner are still needed. v1.1.0, MIT, active but immature.

Trial (one day, after DSH install, L4 protection as prerequisite): one Rust fixture, two proposal branches, 10 checkpoints + a failure/rollback vs git/scratch on the same WSL fs. Proceed only with zero silent loss/unauthorized writes and >=2x checkpoint/rollback speed or >=50% less disk at <=10% build slowdown.
