Requested by the owner 2026-11-07. Keep a maintained table of characters, with reference images and visual traits, so sticker descriptions can name characters the vision model does not know, such as anthropomorphized LLMs and recent anime.

Planning only: how the table is filled, stored and used by the caption step is undecided.

Each entry is expected to hold: the character's name and aliases, the work or origin, reference images, and distinguishing visual traits.
<!-- moldloft:tech_notes -->
Related to #82, whose benchmark should show which character classes the models miss, and so what this table needs to cover. Its anthropomorphized-LLM class is the case expected to depend on this table, which is untested.
Sending the whole table with every caption call gets costly as it grows, particularly with reference images, so selection needs thought.
Existing stickers can be redone with `aglibot stickers-recaption` once the table is in use (uncommitted as of filing).
