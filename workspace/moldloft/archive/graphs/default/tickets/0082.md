Requested by the owner 2026-11-07. The owner sees sticker descriptions misidentify meme characters, especially anthropomorphized LLM characters and recent anime. Measure this on real collected images before changing the caption model.

Scope:
- About 30 images from data/media in four classes: anthropomorphized LLMs, recent anime, well-known older characters, and images that should name no character (control). The owner labels the correct character and aliases, or "none".
- Compare 3 vision models (gemini-3.8-flash, gemini-4-argon-low, gemini-4-argon-medium) against prompt variants, starting with the prompt that shipped with this ticket. That is 180 calls with 2 variants.
- Score each answer as correct, no name, or wrong, by class. Wrong names are the main measure, since they enter the retrieval vector and the chat record.
- A standalone script. It does not touch the bot or the database, and bench calls are not mixed with the bot's budget accounting.

Done when: a results table per model, prompt and class is in docs/research/, with a recommendation on the caption model and prompt, for the owner to decide.

Starting point, 2026-11-07: the newest 37 of 163 descriptions name characters inconsistently: in the description, only in tags, or not at all. Accuracy was not checked, since no images were viewed.
The prompt in src/mind/media.rs SYSTEM now requires naming recognized characters and writing appearance only when unsure. Descriptions written before that change are not comparable, so the bench should generate fresh ones.
Expected but untested: anthropomorphized LLM characters are too new for any model, and may need a glossary or owner corrections in the sticker page rather than a model change.
Relay calls are slow (about 34-45 s end to end in the two live runs) and are billed. Copy the sample out first: files of images that did not become stickers are deleted 7 days after last seen.
