## 结论

1. **Gemini 的判断一半对。** 有几块确实只写不读，或者在生产里没开：knowledge 笔记没有任何读端；reciprocity 产出的 trust/intimacy 只有它自己和人物卡用；episode 向量召回在仓库配置里没开；flow 分桶在两层架构下作用很小。这些可以留在删除状态。
2. **另一半是产品目标本身。** 周成长、commitments、lessons 和 Widen、群卡都是聊天或决策的真实输入。删掉它们，等于放弃了 DESIGN §1a/§1c/§2d/§6 里"会成长、记得答应过谁、能从经历学习"这几个承诺。主人在 #84 也明确要求保留有界成长。
3. **两位评估者的共识：** 恢复成长（只保留有界数值，加探针），恢复 lessons 和 Widen，简化恢复 commitments；进化执行链退役，只保留提案入口；向量召回和自动 watchlist 研究搁置；reciprocity 评分器删除。
4. **任何功能返工之前，先修上线阻断项。** 这些是迁移、旧任务补充、部署流程和 Telegram 代理的问题，不修就会丢数据或停机。见下文"返工前置"。

## 分歧与合并意见

**分歧 1：知识卡排第几（Astra 排前三，Opus 排在研究执行器稳定之后）。** Astra 的依据是 DESIGN §9 有明确验收（"之后问它时它能引用相关卡片"），而且"受过教育"是这个项目的定位。我的依据是：590a346 里这项能力从来没有读端，native 研究也不产出论断台账，所以这不是"恢复"，而是从零新做读写两端。双方都同意不恢复 547 行的聚类器。合并意见：作为新功能登记，在 native ResearchWorker 跑稳几次真实任务之后再做。如果主人认为"受过教育"比"记得答应过谁"更重要，就和 commitments 对调。

**分歧 2：lessons 和 Widen（Opus 原想等 #84，后来改为同意恢复）。** 我改主意的原因是：`SelfOnly` 的 lessons 只能用在独处思考，进不了任何有他人在场的对话，所以单独恢复 lessons 不会改变他和人说话的方式；能让"上次吃过亏，下次换个做法"出现在对话里的，只有通过 Widen 审查的公开副本。`n-agli-dec-widen` 已经被接受，不受 #84 阻塞。恢复的前提是修掉 Astra 指出的问题：审查本身也要服从处理权限，不能拿 `Any` 去看尚未脱敏的候选。

> **更正（2026-11-23，线上数据审查后）**：上面说公开副本能让经验"出现在对话里"，这一点在 590a346 并不成立。普通聊天的召回固定传 `include_lessons: false`，`privacy::recall` 只在独处听众下读 lessons，所以 255 份公开副本从未进入任何聊天。结论（lessons 和 Widen 一起恢复）不变，但工作量比原先估计的大：要第一次做聊天读端，并且先让公开副本可以撤销、重做审查判据。线上 250 条自动通过项里，Astra 和 Opus 认为有 48 条不应原样公开。详见 [lessons-widen-review.md](lessons-widen-review.md)。

**分歧 3：flow（Astra 想简化恢复，Opus 认为保持删除）。** Astra 想要的是忙时稍后回复、事后续接、主人可以打断。Hands v2 已经覆盖了大部分：长任务在后台 worker 里跑，人格层仍能聊天；运行中的补充有序号和消费记录；`/stop` 可以取消任务。剩下需要做的是 R09，即任务标题只对获准的受众显示，这属于修 bug，不需要恢复 flow 模块。DESIGN §4 应改写成只保留 prompt 分层和缓存前缀纪律。

**分歧 4：学习型群观察（Astra 想简化恢复，Opus 想搁置）。** 现在的群聊提示已经读取手写群卡 `mind/social/groups/<id>.md` 和主人维护的群词典（#80）。学习型观察的成本很低（搭在 extract 上），但会让模型推断的群规范直接进入群聊提示。合并意见：搁置；将来如果要做，就让模型提议词条，经主人确认后写进词典，而不是直接生成规范卡。

**分歧 5：DSH（Astra 主张恢复为显式选项，Opus 主张 native 作默认、DSH 搁置）。** Astra 的出发点是 `n-agli-dec-hands` 已被接受，DSH 是主人指定的"主要双手"，能续会话、收工具事件。我的出发点是：这次重构的起因正是进度太慢，而 DSH 这条路上还压着 #25、#27、专用凭据、未知花费和 1,164 行适配代码；native 已经能完成"计划、检索、抓取、报告、审查"的闭环，也更容易测试和取消。两人都同意，无论选哪个，都不能像现在这样静默把 `dsh` 改成 native。**这需要主人在两者之间选一个**，选 native 就补一条决策笔记，替代 `n-agli-dec-hands` 里关于 DSH 的条款。
